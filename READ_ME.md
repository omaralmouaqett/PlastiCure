# PlastiCure — GitHub Pages

A portfolio-grade, single-page presentation of PlastiCure, a student innovation project combining AI, autonomous underwater robotics and biotechnology to address aquatic plastic pollution.

## Deploy on GitHub Pages

1. Create or open the repository you want to use for the PlastiCure project.
2. Copy the contents of this folder into the repository root.
3. Commit and push.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and the `/ (root)` folder.
7. Save. GitHub will publish the site at your repository's Pages URL.

No build system, npm install, framework or server is required.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual system
- `script.js` — mobile navigation + scroll progress
- Wikimedia Commons — reusable image assets are loaded from their original Wikimedia URLs
- `SOURCES.md` — factual and image attribution sources
